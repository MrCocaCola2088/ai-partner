# AI Partner

Sitio bilingüe (ES/EN) construido con Next.js 15 para presentar servicios premium de implementación de IA y dirigir conversiones al diagnóstico gratuito y la reserva de llamadas.

## Desarrollo

```bash
npm install
npm run dev
```

## Variables de entorno

Copia `.env.example` a `.env.local` para desarrollo web y a `.env` si usarás Docker Compose. `NEXT_PUBLIC_BOB_EXCHANGE_RATE` parte de una referencia inicial de 6.96 BOB/USD y debe ajustarse según tu operación.

## Verificación

```bash
npm run lint
npm run build
```
